# Chindu Clips

Studio privé de clipping en français. Frontend statique dans dist/, moteur Python/Docker dans engine/.

Le site est publié avec une démonstration clairement identifiée. Le traitement réel nécessite de lancer le moteur fourni sur un ordinateur ou un serveur, puis de le connecter dans les paramètres. Aucun moteur distant ni abonnement n'a été provisionné. Voir engine/README.md pour l'installation.

Validation : contrôle de syntaxe JS/Python ; quatre tests Python couvrant classement, chevauchement, SRT et export FFmpeg réel (coupe, dimensions, durée). Interface, démonstration et éditeur inspectés dans le navigateur. Le téléchargement YouTube et la transcription Whisper n'ont pas été validés de bout en bout dans l'environnement de création.

Le score des extraits est une heuristique éditoriale locale. Il ne prédit pas la viralité. Le recadrage utilise un fond flouté sans suivi de visage.
